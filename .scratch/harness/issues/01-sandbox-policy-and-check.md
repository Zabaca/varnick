# 01 — Establish the sandbox under `srt`

**What to build:** Launching varnick establishes a real `sandbox-runtime` policy scoped to the clone, and the surface says so only when it fails. Today `checkSandbox` resolves after a timer, so `sandbox.available` means nothing was checked. After this, a developer can read which paths and hosts the policy permits and decide whether they believe the boundary before walking away from it — and if the policy cannot be established, the surface says the agent will not run unconfined and offers to try again.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**Realizes:** `sandbox.checking`, `sandbox.available`, `sandbox.unavailable`

The policy is generated by the Harness package and stays editable in the clone — the thing a fork most wants to change is the boundary. The Agent SDK's own `sandbox` option is disabled and must stay disabled: the kernel refuses to apply a sandbox inside an existing one and every `Bash` command dies with exit 71 ([ADR-0003](../../../docs/adr/0003-containment-wraps-the-process-tree.md)).

- [ ] Home directory, other repositories, and the network are denied except for the allowlist
- [ ] `packages/core/**`, `vite.config.*` and `package.json` are unwritable ([ADR-0002](../../../docs/adr/0002-core-userspace-boundary.md))
- [ ] `security`, `osascript`, `open` and `sudo` are denied by denying **read** — `srt` has no execute allowlist, and a narrow deny must win over the broad allow that re-opens system paths
- [ ] One shell-level probe proves the boundary holds: a command run under the policy cannot read the home directory. Not the full suite — that is ticket 04, which needs an agent — but enough that this ticket ships "the boundary holds" rather than "the policy compiles"
- [ ] Breaking the policy on purpose reaches `sandbox.unavailable` carrying the real reason, and `#/states → sandbox-unavailable` renders unchanged against the real actor
- [ ] The permitted paths and hosts are readable by a developer without reading the source
- [ ] No state, flag, or debug path exists that starts the agent unconfined

Covers stories 1, 3, 4, 5, 6, 7, 10, 33.
