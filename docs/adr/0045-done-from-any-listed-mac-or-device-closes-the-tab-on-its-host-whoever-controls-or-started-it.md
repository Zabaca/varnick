# Done from any listed Mac or device closes the tab on its host, whoever controls or started it

Supersedes parts of [ADR 0032](0032-a-tabs-done-mark-belongs-to-its-host-and-completed-lists-tabs.md) (a `done` request marks and ends nothing, only a Mac may send it, and an open tab can be marked) and amends [ADR 0034](0034-a-tab-lives-on-one-host-which-keeps-its-layout-panes-and-mark-and-other-devices-view-or-take-over-the-tab-whole.md) (only the machine in control changes a tab, and `tabs` lists the tab's mark). Option 03 of `phone-cant-mark-a-tab-done` is the spec, and the user's answers of 2026-10-20 are recorded in it: "just provide done globally. before i thought there would be contention over owner but its all me, one user. i control all these devices, im the one that opens, creates, marks done. there is no someone else today."

The rule is across machines and the protocol encodes it (version 33), so it is hard to undo:
- **Done is global.** Any Mac or device the host lists may send `done` for any tab of the host, in control of it or not, and whoever started it. The host closes the tab as its own Done does: every pane ends (Claude sessions, terminals, pages, apps and files), and the tab goes to Completed and to Recent. The host asks no question of its own: the asker asked.
- **A `done` request closes an open tab and marks a closed one.** On a Mac host an open tab with a Claude pane closes through the model, as its Done does; one with no Claude pane is refused, as a Mac's Done needs one. On a headless host the open records of the tab are ended, their sessions killed and their mark set, in one write; a tab with no Claude record open is refused. A closed tab is marked as before (from its ended card or Recent into Completed on a Mac; on the records of a headless host), and `mark` false takes a closed tab's mark off. A tab the host does not have is refused. A Mac host replies to an open tab's `done` once the tab has left its tabs and is saved (a short wait, else a refusal saying it is still closing), so the asker's next listing cannot show it running.
- **An open tab carries no mark.** The mark on a saved open tab, its "Still open here" Completed card and its reading as the tab closes are gone, and so is the mark in `tabs` (`doneAge` on `PeerTab` and `PeerOpenSession`). A Mac's `sessions.json` keeps its shape: an open tab saved with a mark is read once and saved without it, open and unmarked. A headless record marked while open keeps its mark and takes it to Recent when it closes.
- **A Mac's Done on another machine's tab is the same one request.** It replaces the `end` and then the `done` that handed the tab back as "Still open here", and the mark alone a board card with no copy sent. It asks first by the Mac's own rule (while a Claude session of the tab works, from the host's listing for a card with no copy), sends `done` and waits. If the host takes it, the copy here closes as a Done that sends no `end`, and the tab goes into Completed flagged as the host's mark. If the host refuses, or cannot be reached, nothing closes and nothing is marked here: the tab still runs there, and its card says why for a few seconds.
- **An ended card's Done stays as it was:** Completed with the mark sent to the host, and "Done on this Mac only" when the host does not take it. The clear before a reopen, "Still open on <Mac>" for a Completed tab whose host still lists it open, and the listing's removal of a flagged mark from a tab listed open all stay.
- **A pane in control on another machine whose session ends without this Mac's own close waits for that host's Recent,** as a view's pane does, so a tab another device marked Done lands in Completed here, not in Stopped.
- **The Phone page's tab view puts Done, Redraw and Restart in a menu** beside End (the bar is the title, a menu button and End). Done is offered in any tab with a Claude pane, in control or not, and always asks first in the page's own dialog; Redraw and Restart keep their rules, Restart acting on the pane shown. `POST /api/done` sends `done` for the tab as the device. The single-session view's menu holds Redraw only. The Phone page's Done when the host cannot be reached says so and closes nothing; there is no local fallback for an open tab.
- **`end` is unchanged,** and so is its origin rule: the phone's End ends a tab it made and hands back any other. Done is how a device finishes any tab.

## Considered Options

- **Done as `end` plus the mark, taken only from the machine in control (option 02):** rejected by the user. Contention over an owner is not a case there is one user and no one else, and the control gate made Done unavailable on a tab a Mac held.
- **Done in a tab the phone controls as `done` then `end` (option 01):** rejected by the user. It leaves a tab the phone did not start handed back and running, and the mark on an open tab it needed.
- **A fallback of "Done on this Mac only" for an open tab whose host cannot be reached:** rejected. It would hide a tab that still runs. An ended card keeps it, since nothing is left to end.
- **Done offered on a tab with no Claude pane:** not offered, and refused by both hosts, as a Mac's Done needs a Claude pane today and the board lists only such tabs.

## Consequences

- **A protocol bump to 33.** `done`'s meaning changes and `tabs` loses a field. A Mac left on version 32 is refused, as for any bump; the headless host is reinstalled from a Mac with the installer, its page included.
- **A Done can end work the device cannot see running,** such as a terminal, a dev server or a session mid-turn, as Done on the Mac does. The question says every pane ends; the Mac asks while a session works and the phone always asks.
- **A Done that cannot reach its host does nothing,** so the tab stays on the board and keeps running.
- **A listed device can now end any tab of a host by Done,** not only a tab it made. That is within what a listed device can already do on a host (`docs/privacy-and-security.md`); if the user ever shares a host, it is the rule to revisit.
- **Undo is a reopen:** Resume from the Phone page's Recent, or ↩ on a Completed card on a Mac, reopens the tab and takes it out of Completed everywhere.
- **Sending a Done again once its host answers stays out,** as in ADR 0032.
